# RoyalVigor — متجر الحيوية والعناية الطبيعية (Algeria COD E-Commerce)

منصة تجارة إلكترونية كاملة وخفيفة مصممة خصيصاً للسوق الجزائري والدفع عند الاستلام (Cash on Delivery) عبر كافة الـ 58 ولاية، مع لوحة تحكم إدارية متطورة لإدارة الطلبيات والاتصال المباشر بالزبائن.

---

## 🌟 أبرز ميزات المتجر (Store Features)

1. **واجهة مستخدم عصرية وسريعة (Crisp Modern Design):**
   - تصميم متناسق وجذاب باللون الأخضر الزمردي والفحمي النقي.
   - ثنائي اللغة: العربية (RTL) والإنجليزية (LTR).
   - حل نهائي لمشكلة اتجاه الأرقام والهواتف في اللغة العربية (BiDi LTR Isolation).
   - شريط عائم سفلي ثابت للجوال للطلب السريع والاتصال المباشر عبر الهاتف أو واتساب.

2. **كتالوج المنتجات الـ 7 بالأسعار العادية المضبوطة:**
   - عسل السر العثماني: `3,600 د.ج`
   - عسل شداد القوة: `4,500 د.ج`
   - عسل هيلتي التركي: `6,500 د.ج`
   - عسل الملوك الملكي (BIO-HERBS): `4,500 د.ج`
   - عسل فيتاماكس دبل شوت (VITAMAX): `4,500 د.ج`
   - قوة الحصان (Power Horse): `3,800 د.ج`
   - ليوغرا 200 ملغ (Liogra-200): `2,900 د.ج`

3. **لوحة تحكم إدارية (`/admin`):**
   - متابعة الطلبيات الجديدة بحالة **"بحاجة للاتصال"** (`pending_call`).
   - زر **اتصال هاتفي مباشر** بنقرة واحدة برقم الزبون (`tel:0664936133`).
   - زر **تأكيد فوري عبر واتساب** بنص جاهز ومفصل يضم كافة بيانات الطلبية.
   - طباعة وصل الشحن والتوصيل الرسمي (*Bon de Livraison*).
   - إمكانية تصدير الطلبيات كملف Excel / CSV.
   - تعديل أسعار الشحن والتوصيل لجميع الولايات (58 ولاية) لباب المنزل أو استلام المكتب (*Stop Desk*).

4. **الأمان والمصداقية (Security Hardened):**
   - التحقق من السعر الحقيقي في الخادم (Server-Side Price Validation) لمنع التلاعب بالأسعار.
   - الحماية من ثغرات الحقن (Stored XSS Sanitization) لجميع مدخلات الزبائن.
   - قاعدة بيانات خفيفة ومرنة محفوظة في ملفات JSON دون الحاجة لتهيئة خوادم قواعد بيانات معقدة.

## 🚀 طريقة التشغيل محلياً (Run Locally)

```bash
# تثبيت الحزم المطلوبة
npm install

# تشغيل الخادم
node server.js
```

- رابط المتجر: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin` (تتطلب كلمة مرور المشرف المعقدة المحددة في الإعدادات)

## 🌐 خطوات النشر المباشر على الإنترنت (How to Deploy Live)

### الطريقة الأسهل والأسرع: عبر موقع [Render.com](https://render.com) (مجاناً)
1. سجل دخول إلى [Render.com](https://render.com) باستخدام حساب GitHub الخاص بك (`adaam1101`).
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر مستودع **`royalvigor-shop`**.
4. اضبط الإعدادات التالية:
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
5. اضغط على **Create Web Service**، وخلال دقيقتين سيعطيك Render رابطاً حياً مجانياً يعمل 24/7 (مثلاً: `https://royalvigor.onrender.com`).
6. يمكنك لاحقاً ربط اسم نطاق خاص بك بسهولة (Custom Domain مثل: `royalvigor.dz` أو `royalvigor.com`).
